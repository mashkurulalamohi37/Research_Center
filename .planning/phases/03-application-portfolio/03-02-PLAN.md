# Plan 03-02: Applications Catalog, Product Detail Pages & Router Registration

## Objective
Implement the interactive applications showcase catalog at `/apps` and the dynamic individual product landing pages at `/apps/:slug`, wiring both into `src/App.tsx` and verifying build stability.

---

## Tasks

<task id="1">
<title>Build Applications Catalog Page (Apps.tsx)</title>
<action>
1. Create `src/pages/public/Apps.tsx`:
   - Hero banner displaying the 10-application proprietary portfolio.
   - Filter pills by category: All, Digital Healthcare, Agricultural AI, Education & Academic AI, Enterprise AI & IoT.
   - Search bar filtering by name, keywords, and tech stack.
   - High-contrast responsive card grid rendering:
     - Bespoke `AppVectorIcon`
     - Status badges (`Production`, `Beta`, `Clinical Trial`)
     - Short description and key capability pills
     - Direct CTA linking to `/apps/:slug`
</action>

</done>
</task>

<task id="2">
<title>Build Dynamic Application Detail Page (AppDetail.tsx)</title>
<action>
1. Create `src/pages/public/AppDetail.tsx`:
   - Parse `:slug` parameter from URL and load application record.
   - Fallback graceful redirect/notice if slug is invalid.
   - Hero banner with `AppVectorIcon`, app name, subtitle, version, and status badge.
   - Interactive Live Demo Simulation / Test sandbox mockup.
   - Core Features & Capabilities grid.
   - System Architecture & Engineering Specifications (models, protocols, databases).
   - Target Users & Deployment Scenarios.
   - Next/Previous application navigation bar.
</action>
<verify>

</verify>
<done>
All 10 applications have deep-dive landing pages with architecture specifications.
</done>
</task>
