# Plan 04-01: Organizational Ecosystem Matrix (10 Divisions)

## Objective
Implement the 10-Division Organizational Ecosystem Matrix with comprehensive dataset, interactive Table/Grid component, and dedicated `/divisions` and `/divisions/:slug` pages.

## Tasks
1. Create `src/data/divisions.ts` defining all 10 divisions with mandates, key initiatives, focus areas, associated apps, and metrics.
2. Build `src/components/home/EcosystemGrid.tsx` with dual Grid/Table view modes, focus filtering, and interactive preview modal/drawer.
3. Build `src/pages/public/Divisions.tsx` providing a dedicated institutional division browser and deep-dive detail view.
4. Mount `EcosystemGrid` on the Homepage (`src/pages/public/Home.tsx`) and register dedicated `/divisions` and `/divisions/:slug` routes in `src/App.tsx`.
5. Verify build integrity (`npm run build`).

## Success Criteria
- All 10 divisions defined in strict accordance with Requirement 4.
- Table / Grid toggle functions cleanly on Homepage and `/divisions`.
- Cross-links to `/apps/:slug` and `/experts` work without dead `#` links.
- `tsc && vite build` succeeds with zero errors.
