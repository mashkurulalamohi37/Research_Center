# Plan 02-01: Navigation Schema, Category Hub Engine & Route Registration

## Objective
Establish the unified 10-category navigation data model in `src/data/navigation.ts` and create all required route targets and dynamic hub components in `src/App.tsx` so that every navigation item resolves to an active, functional view (zero dead `#` links).

<task id="1">

<action>

   - Strongly type categories 01 through 10:
     - 01: About IRICC / AIRIC (Core, Leadership Roles, 12 Resource Persons Directory domains)
     - 02: Research & Publications (Published, Present, Presentations, Completed/Ongoing Projects, JAIR/JAIRIC Journals, Datasets)
     - 03: Innovation & Entrepreneurship Center (Projects, Entrepreneurship, Incubation, Young Innovators, Product Dev, Tech Transfer)

     - 07: Professional & Expert Network (AI Engineers, Cyber Engineers, Researchers, Data Analysts, Healthcare Experts, Medical Consultants)
     - 08: Health & Wellbeing (Digital Health, Consultation, Mental Health, Health Research)
     - 09: Contact & Collaboration (Researcher, Membership, Proposal, Industry, Contact)
     - 10: Automation Center (Workflows, Tools, API Hub)
