**Version:** 1.0

---

# 1. Project Overview

The **Advanced Intelligent Research Center (AIRC)** website will be developed as a modern, scalable, research-focused digital platform representing the center's academic activities, researchers, projects, publications, events, opportunities, collaborations, and technological achievements.

The platform should not be treated as a simple informational website.

It should be designed as:

> **A professional research institution website + research management platform + researcher portal + content management system.**

The public website will provide information about AIRC to students, researchers, universities, industries, collaborators, funding organizations, and the general public.

The authenticated platform will allow authorized AIRC members and administrators to manage research activities, publications, projects, events, resources, applications, and website content.

# 54. Important Frontend Decision

Do not mix React and Quasar for the same application.

Quasar is based on Vue.

Choose one frontend ecosystem.

Recommended AIRC stack:

```text
React
+
TypeScript
+
Tailwind CSS
+
shadcn/ui
```

If the team specifically prefers Vue, use:

```text
Vue
+
TypeScript
+
Quasar
```

But do not build the same UI using both React and Quasar.
